## 4. 与设计、与原来的 Python 实现不一样的地方

- 取消命令时沙箱没确认停下：Python 原来留着环境，只报 `UNDO_FAILED`。现在服务拒绝这个借用上之后的命令（`exec_not_stopped`），直到还掉，所以还原检查点一定报失败、不会误报“已还原”。
- Workspace API 不再有“没配沙箱就直接在工作区目录里做”这条路：没配服务时报 `workspace_api_unavailable`。CLAUDE.md 的 Workspace 一行要跟着改。
- `EnvRecord` 里没有 `allow_hosts`。托管后端按域名放行的名单只在服务的环境表里，Worker 只看得到 `Lease.network = allowlist`。要给 Worker 看就得改契约。
- 设计书原文档要人改的：4.10、4.14、4.15、附录 A（SBX-01 稿第 9 节）。
