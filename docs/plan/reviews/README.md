实施计划 1.3 第 2 条“写审分离”：强档写的，由另一家的强模型或人来审。R-01 到 R-06 的实现与第一份评审都出自 Claude（Anthropic），

## 材料包

每份复审只给 6.2 列出的四样东西，不给之前的评审文档，也不给实现过程：

1. **评审模板**：6.2 的模板，补一句仓库是什么、diff 只含非测试源码。
2. **工作项全文**：实施计划第 5 节对应的一行评审重点；TMP 计划对应的工作包（到“结果”之前）；工作项的细化文档里的范围、难点与防错、决定。
3. **设计书相关章节**：按 6.2 的 `{章节}` 原样摘出。
4. **diff 与测试结果**：对应提交的 `git show`（去掉 `*_test.go`、`tests/`、golden 历史与测试替身），另附几段评审重点直接相关的当前代码（带行号）；
   测试文件只列名字；测试结果是评审前在本机跑出的摘要。
