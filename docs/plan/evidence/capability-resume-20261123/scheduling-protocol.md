# 能力矩阵的预算中断重放协议

2026-11-23。在变更调度、汇总本轮成绩之前登记。

问题是一次任务被预算、时间窗口或外部服务中断时，某些角色连第一道题都没有启动。历史运行的计划与队列把角色、评测器、候选依次串行排在一起。候选策略是在固定的基础阶段内按角色轮转，每个角色内部再按“评测器 × 候选”轮转；对高价候选仍只先投放淘汰赛预选，晋级及追加样本继续按原规则决定。

使用 round1 留下的真实结果行按原归档顺序回放，截断点预设为第100、500、1,000条记录。再用新 transform 运行的全部真实结果，在第18、100条处回放。原序与轮转共用同一批行，各个“角色 × 评测器 × 候选”内相对顺序不变。使用决定进入淘汰赛之后的观测作重放时，去掉晋级才可能产生的付费观测。未观测的历史单元不补数据。结果报告截断时触达的角色数、已尝试的候选评测单元数，以及在该窗口至少有一次明确命中且有效的单元数。

这项重放衡量观测覆盖。相同的条数不代表相同耗时或金额；提供各窗口的可见费用作解释。矩阵原始得分仍由真实冻结运行计算。
